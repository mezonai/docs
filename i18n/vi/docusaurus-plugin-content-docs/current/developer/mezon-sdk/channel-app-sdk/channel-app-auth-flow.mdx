# Kiểm tra ai đã mở ứng dụng

Khi thành viên khởi chạy ứng dụng trong kênh của bạn, Mezon thêm tham số `data` vào URL của ứng dụng. Tham số này chứa ID, tên người dùng, tên hiển thị và ảnh đại diện của thành viên, được ký bằng token của ứng dụng. Máy chủ của bạn kiểm tra chữ ký, rồi tin danh tính của thành viên mà không cần đăng nhập riêng.

## Cách hoạt động {#how-it-works}

1. Thành viên nhấn **Khởi chạy ứng dụng** trong Mezon. Mezon ký dữ liệu của thành viên bằng token của ứng dụng và mở URL của ứng dụng kèm `?data=...` (xem [Ứng dụng trong kênh](./overview.md)).
2. Trang web của bạn đọc `data` từ URL và gửi lên máy chủ.
3. Máy chủ kiểm tra chữ ký bằng **Token** của ứng dụng lấy từ Developer Portal.
4. Nếu chữ ký hợp lệ, máy chủ tạo phiên cho thành viên đó.

Đừng kiểm tra chữ ký trong trình duyệt: việc đó cần token, mà token phải nằm trên máy chủ.

## `data` chứa gì {#what-data-contains}

`data` là một chuỗi truy vấn gồm năm tham số, theo thứ tự sau:

```text
query_id=AbCdEfGhIjKlMnOpQrStUvWx&user=%7B%22id%22%3A1234567890123456789%2C...%7D&auth_date=1795083705&signature=ZGM5...%3D%3D&hash=e30db1ab...
```

| Tham số | Ý nghĩa |
|---|---|
| `query_id` | Một chuỗi ngẫu nhiên gồm 24 ký tự. |
| `user` | Thông tin thành viên, dạng JSON đã mã hóa URL. |
| `auth_date` | Thời điểm Mezon ký dữ liệu, tính bằng giây Unix. |
| `signature` | Chữ ký thứ hai, chỉ trên `auth_date`. Bạn không cần nó để kiểm tra `hash`. |
| `hash` | Chữ ký của mọi thứ đứng trước `&hash=`, gồm 64 ký tự thập lục phân. |

JSON của `user` có dạng:

```json
{
  "id": 1234567890123456789,
  "username": "mai.nguyen",
  "display_name": "Mai Nguyen",
  "avatar_url": "https://example.com/avatar.png"
}
```

`id` là một số JSON có tới 19 chữ số. `JSON.parse` của JavaScript làm tròn các số lớn hơn 2^53, nên hãy đọc `id` dưới dạng chuỗi (ví dụ Node.js bên dưới làm như vậy). Trường nào trống thì không có mặt.

## Kiểm tra chữ ký {#check-the-signature}

Mezon tính `hash` như sau:

1. `secret` = mã băm MD5 của token ứng dụng, viết thành 32 ký tự thập lục phân chữ thường.
2. `key` = HMAC-SHA256 của chuỗi `WebAppData`, với khóa là `secret`.
3. `hash` = HMAC-SHA256 của mọi thứ trong `data` đứng trước `&hash=`, với khóa là `key`, viết thành chữ thập lục phân thường.

Máy chủ của bạn lặp lại ba bước trên với `data` nhận được và so kết quả với `hash`. Hãy dùng đúng chuỗi mà trang web đã đọc: đừng giải mã thêm lần nữa và đừng sắp xếp lại các tham số.

Mezon không giới hạn tuổi của `data`. Hãy tự kiểm tra `auth_date`; các ví dụ chấp nhận dữ liệu trong vòng năm phút.

Mỗi ví dụ trả về thông tin thành viên, hoặc không trả về gì nếu dữ liệu không hợp lệ. Tất cả đã được thử với dữ liệu tạo theo đúng cách Mezon tạo.

```js
const crypto = require("node:crypto");

function checkMezonData(data, appToken, maxAgeSeconds = 300) {
  const at = data.lastIndexOf("&hash=");
  if (at < 0) return null;
  const signed = data.slice(0, at);
  const hash = Buffer.from(data.slice(at + "&hash=".length));

  const secret = crypto.createHash("md5").update(appToken).digest("hex");
  const key = crypto.createHmac("sha256", secret).update("WebAppData").digest();
  const expected = Buffer.from(crypto.createHmac("sha256", key).update(signed).digest("hex"));
  if (hash.length !== expected.length || !crypto.timingSafeEqual(hash, expected)) return null;

  const params = new URLSearchParams(signed);
  const authDate = Number(params.get("auth_date"));
  if (!(Date.now() / 1000 - authDate <= maxAgeSeconds)) return null;

  const userJson = params.get("user") ?? "";
  const user = JSON.parse(userJson);
  user.id = /"id":(\d+)/.exec(userJson)?.[1]; // keep the 64-bit id as a string
  return user;
}

module.exports = { checkMezonData };
```

```python
import hashlib
import hmac
import json
import time
from urllib.parse import parse_qs


def check_mezon_data(data: str, app_token: str, max_age_seconds: int = 300):
    signed, sep, received_hash = data.rpartition("&hash=")
    if not sep:
        return None

    secret = hashlib.md5(app_token.encode()).hexdigest()
    key = hmac.new(secret.encode(), b"WebAppData", hashlib.sha256).digest()
    expected = hmac.new(key, signed.encode(), hashlib.sha256).hexdigest()
    if not hmac.compare_digest(expected, received_hash):
        return None

    params = parse_qs(signed)
    if time.time() - int(params["auth_date"][0]) > max_age_seconds:
        return None
    return json.loads(params["user"][0])
```

```go
package main

import (
	"crypto/hmac"
	"crypto/md5"
	"crypto/sha256"
	"encoding/hex"
	"encoding/json"
	"errors"
	"net/url"
	"strconv"
	"strings"
	"time"
)

type MezonUser struct {
	ID          int64  `json:"id"`
	Username    string `json:"username"`
	DisplayName string `json:"display_name"`
	AvatarURL   string `json:"avatar_url"`
}

func CheckMezonData(data, appToken string, maxAge time.Duration) (*MezonUser, error) {
	at := strings.LastIndex(data, "&hash=")
	if at < 0 {
		return nil, errors.New("no hash")
	}
	signed, received := data[:at], data[at+len("&hash="):]

	sum := md5.Sum([]byte(appToken))
	secret := hex.EncodeToString(sum[:])
	mac := hmac.New(sha256.New, []byte(secret))
	mac.Write([]byte("WebAppData"))
	mac = hmac.New(sha256.New, mac.Sum(nil))
	mac.Write([]byte(signed))
	expected := hex.EncodeToString(mac.Sum(nil))
	if !hmac.Equal([]byte(expected), []byte(received)) {
		return nil, errors.New("bad hash")
	}

	params, err := url.ParseQuery(signed)
	if err != nil {
		return nil, err
	}
	authDate, err := strconv.ParseInt(params.Get("auth_date"), 10, 64)
	if err != nil || time.Since(time.Unix(authDate, 0)) > maxAge {
		return nil, errors.New("expired")
	}
	var user MezonUser
	if err := json.Unmarshal([]byte(params.Get("user")), &user); err != nil {
		return nil, err
	}
	return &user, nil
}
```

```csharp
using System.Security.Cryptography;
using System.Text;
using System.Text.Json;
using System.Web;

public record MezonUser(long Id, string Username, string DisplayName, string AvatarUrl);

public static class MezonData
{
    public static MezonUser? Check(string data, string appToken, TimeSpan maxAge)
    {
        var at = data.LastIndexOf("&hash=", StringComparison.Ordinal);
        if (at < 0) return null;
        var signed = data[..at];
        var received = data[(at + "&hash=".Length)..];

        var secret = Convert.ToHexString(MD5.HashData(Encoding.UTF8.GetBytes(appToken))).ToLowerInvariant();
        var key = HMACSHA256.HashData(Encoding.UTF8.GetBytes(secret), Encoding.UTF8.GetBytes("WebAppData"));
        var expected = Convert.ToHexString(HMACSHA256.HashData(key, Encoding.UTF8.GetBytes(signed))).ToLowerInvariant();
        if (!CryptographicOperations.FixedTimeEquals(Encoding.ASCII.GetBytes(expected), Encoding.ASCII.GetBytes(received)))
            return null;

        var query = HttpUtility.ParseQueryString(signed);
        var authDate = DateTimeOffset.FromUnixTimeSeconds(long.Parse(query["auth_date"] ?? "0"));
        if (DateTimeOffset.UtcNow - authDate > maxAge) return null;

        using var user = JsonDocument.Parse(query["user"] ?? "{}");
        var root = user.RootElement;
        return new MezonUser(
            root.GetProperty("id").GetInt64(),
            root.TryGetProperty("username", out var u) ? u.GetString() ?? "" : "",
            root.TryGetProperty("display_name", out var d) ? d.GetString() ?? "" : "",
            root.TryGetProperty("avatar_url", out var a) ? a.GetString() ?? "" : "");
    }
}
```

## Gửi `data` từ trang web {#send-data-from-your-page}

Trang web đọc `data` bằng `URLSearchParams`, hàm này giải mã đúng một lần, như cần thiết. Sau đó trang xóa `data` khỏi thanh địa chỉ và gửi nó lên máy chủ.

```html
<script>
  const data = new URLSearchParams(location.search).get("data");
  if (data) {
    history.replaceState(null, "", location.pathname);
    fetch("/api/mezon-login", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ data }),
    })
      .then((response) => (response.ok ? response.json() : Promise.reject(response.status)))
      .then(({ user }) => {
        document.body.textContent = `Hello ${user.display_name || user.username}`;
      })
      .catch(() => {
        document.body.textContent = "Open this app with Launch App in Mezon.";
      });
  }
</script>
```

## Nhận dữ liệu trên máy chủ {#receive-it-on-your-server}

Một endpoint Express tối giản dùng hàm Node.js ở trên (lưu thành `check-mezon-data.js`):

```js
const express = require("express");
const { checkMezonData } = require("./check-mezon-data");

const app = express();
app.use(express.json());

app.post("/api/mezon-login", (req, res) => {
  const user = checkMezonData(String(req.body?.data ?? ""), process.env.MEZON_APP_TOKEN ?? "");
  if (!user) return res.status(401).json({ error: "invalid data" });

  // The member is user.id (a string). Create your own session for them here.
  res.json({ user });
});

app.listen(3000);
```

Đặt `MEZON_APP_TOKEN` trên máy chủ bằng token của ứng dụng. Sau khi kiểm tra, hãy tạo phiên riêng cho thành viên (cookie hoặc token), để các yêu cầu sau không cần `data` nữa.

## Xử lý sự cố {#troubleshooting}

| Vấn đề | Nguyên nhân |
|---|---|
| URL không có `data` | Thành viên chọn kênh của ứng dụng thay vì nhấn **Khởi chạy ứng dụng**. Chỉ khi khởi chạy, Mezon mới thêm `data`. |
| `hash` không bao giờ khớp | Token sai hoặc đã bị đặt lại, hoặc `data` bị giải mã hai lần (ví dụ dùng `decodeURIComponent` sau `URLSearchParams`). |
| ID thành viên sai trong JavaScript | `JSON.parse` đã làm tròn ID 19 chữ số. Hãy đọc ID dưới dạng chuỗi. |
