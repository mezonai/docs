# OAuth2

Mezon là nhà cung cấp OAuth2 và OpenID Connect. Trang web của bạn có thể chuyển người dùng sang Mezon để đăng nhập, rồi nhận ID người dùng Mezon, tên người dùng, tên hiển thị và ảnh đại diện của họ. Trang này giải thích luồng mã ủy quyền (authorization code).

## Thiết lập ứng dụng {#set-up-your-app}

1. Mở [Mezon Developer Portal](https://mezon.ai/developers/applications) và mở ứng dụng của bạn (hoặc [tạo một ứng dụng](../quick-start/creating-mezon-app.md)).
2. Mở thẻ **OAuth2**.
3. Ở mục **Chuyển hướng**, nhấn **Thêm Chuyển hướng** và nhập URL nhận kết quả (callback), ví dụ `https://your-app.example.com/callback`. URL phải bắt đầu bằng `http://` hoặc `https://`.
4. Ở mục **Trình tạo URL OAuth2**, trong **Phạm vi**, đánh dấu các scope mà trang web của bạn yêu cầu, rồi lưu thay đổi.
5. Ở mục **Thông tin Client**, sao chép **Client ID**.
6. Nhấn **Đặt lại secret** để tạo client secret, rồi lưu nó trên máy chủ. Bạn cần có ít nhất một redirect URI trước.

Client secret phải nằm trên máy chủ. Luồng trong trang này cần có máy chủ.

## Các endpoint {#endpoints}

Các URL này lấy từ tài liệu khám phá công khai tại `https://oauth2.mezon.ai/.well-known/openid-configuration` (đọc ngày 19/11/2026).

| Endpoint | URL |
|---|---|
| Ủy quyền | `https://oauth2.mezon.ai/oauth2/auth` |
| Token | `https://oauth2.mezon.ai/oauth2/token` |
| Thông tin người dùng | `https://oauth2.mezon.ai/userinfo` |
| Thu hồi | `https://oauth2.mezon.ai/oauth2/revoke` |
| Đăng xuất | `https://oauth2.mezon.ai/oauth2/sessions/logout` |
| Khóa ký | `https://oauth2.mezon.ai/.well-known/jwks.json` |

## Scope {#scopes}

| Scope | Cho bạn |
|---|---|
| `openid` | Một ID token chứa các claim của người dùng (xem [Claim của người dùng](#user-claims)). |
| `offline` | Một refresh token, để lấy access token mới mà không phải hỏi lại người dùng. |

Ứng dụng mới được yêu cầu `openid` và `offline`. Chỉ yêu cầu các scope đã đánh dấu trong danh sách **Phạm vi** của ứng dụng.

## Luồng mã ủy quyền {#authorization-code-flow}

### 1. Chuyển người dùng sang Mezon {#1-send-the-user-to-mezon}

Chuyển trình duyệt của người dùng tới URL ủy quyền:

```text
https://oauth2.mezon.ai/oauth2/auth?client_id=YOUR_CLIENT_ID&redirect_uri=https%3A%2F%2Fyour-app.example.com%2Fcallback&response_type=code&scope=openid%20offline&state=RANDOM_STATE
```

| Tham số | Giá trị |
|---|---|
| `client_id` | **Client ID** của bạn. |
| `redirect_uri` | Một trong các redirect URI của bạn, đã mã hóa URL. Phải khớp chính xác. |
| `response_type` | `code` |
| `scope` | Các scope, cách nhau bằng dấu cách (`%20`). |
| `state` | Một giá trị ngẫu nhiên bạn tạo cho lần đăng nhập này và lưu trong phiên của người dùng. |

`state` chống tấn công giả mạo yêu cầu (CSRF): khi người dùng quay lại, hãy so với giá trị đã lưu, và dừng lại nếu chúng khác nhau. Hãy dùng một giá trị ngẫu nhiên dài, ví dụ 32 ký tự.

### 2. Nhận mã {#2-receive-the-code}

Người dùng đăng nhập vào Mezon. Sau đó Mezon đưa trình duyệt quay về redirect URI của bạn:

```text
https://your-app.example.com/callback?code=AUTHORIZATION_CODE&scope=openid+offline&state=RANDOM_STATE
```

Kiểm tra `state`, rồi đổi `code` lấy token.

### 3. Đổi mã lấy token {#3-exchange-the-code-for-tokens}

Gửi `POST` tới URL token, với nội dung mã hóa dạng `application/x-www-form-urlencoded`. URL token không nhận JSON.

```python
import requests

TOKEN_URL = "https://oauth2.mezon.ai/oauth2/token"
CLIENT_ID = "YOUR_CLIENT_ID"
CLIENT_SECRET = "YOUR_CLIENT_SECRET"
REDIRECT_URI = "https://your-app.example.com/callback"


def exchange_code(code):
    data = {
        "grant_type": "authorization_code",
        "code": code,
        "redirect_uri": REDIRECT_URI,
        "client_id": CLIENT_ID,
        "client_secret": CLIENT_SECRET,
    }
    r = requests.post(TOKEN_URL, data=data)
    r.raise_for_status()
    return r.json()
```

Gửi client id và secret trong nội dung form, như trên. Mezon thiết lập các ứng dụng tạo từ Developer Portal theo cách này (`client_secret_post`).

Phản hồi:

```json
{
  "access_token": "ACCESS_TOKEN",
  "expires_in": 3600,
  "id_token": "ID_TOKEN",
  "refresh_token": "REFRESH_TOKEN",
  "scope": "openid offline",
  "token_type": "bearer"
}
```

`id_token` chỉ có khi dùng scope `openid`, và `refresh_token` chỉ có khi dùng `offline`. `expires_in` là thời gian sống của access token, tính bằng giây.

### 4. Đọc thông tin người dùng {#4-read-the-user}

Gọi URL thông tin người dùng với access token:

```bash
curl -H "Authorization: Bearer ACCESS_TOKEN" https://oauth2.mezon.ai/userinfo
```

## Claim của người dùng {#user-claims}

Với scope `openid`, ID token và phản hồi thông tin người dùng chứa các claim sau, nếu người dùng có giá trị cho chúng:

| Claim | Ý nghĩa |
|---|---|
| `user_id` | ID người dùng Mezon, cũng là ID mà bot, webhook và ứng dụng kênh nhìn thấy. Hãy lưu dưới dạng chuỗi: nó có tới 19 chữ số. Hãy dùng ID này để nhận diện người dùng. |
| `username` | Tên người dùng. |
| `display_name` | Tên hiển thị. |
| `avatar` | URL ảnh đại diện. |
| `mezon_id` | Mã định danh tài khoản do dịch vụ đăng nhập của Mezon cấp, là một chuỗi không mang ý nghĩa. Đây không phải ID người dùng. |
| `email` | Địa chỉ email. |

ID token là một JWT ký bằng RS256. Hãy kiểm tra nó bằng các khóa ở URL khóa ký.

## Làm mới và thu hồi token {#refresh-and-revoke-tokens}

Lấy access token mới bằng refresh token:

```bash
curl -X POST https://oauth2.mezon.ai/oauth2/token \
  -d grant_type=refresh_token \
  -d refresh_token=REFRESH_TOKEN \
  -d client_id=YOUR_CLIENT_ID \
  -d client_secret=YOUR_CLIENT_SECRET
```

Thu hồi token khi người dùng đăng xuất khỏi trang web của bạn:

```bash
curl -X POST https://oauth2.mezon.ai/oauth2/revoke \
  -d token=REFRESH_TOKEN \
  -d client_id=YOUR_CLIENT_ID \
  -d client_secret=YOUR_CLIENT_SECRET
```
