# Tổng quan Webhooks

Webhook trên Mezon là một URL HTTPS bí mật cho phép bất kỳ hệ thống bên ngoài nào — pipeline CI/CD, kho mã GitHub, công cụ giám sát hoặc script backend — gửi tin nhắn vào Mezon chỉ với một yêu cầu `HTTP POST`. Bạn không cần tài khoản bot, phiên WebSocket hay SDK.

Webhook Mezon chỉ hoạt động theo **chiều đi vào (incoming)**: gửi dữ liệu *vào* Mezon. Nếu bạn cần nhận sự kiện từ Mezon, xử lý lệnh chat hoặc hiển thị nút bấm tương tác, hãy tạo [bot](../getting-started/create-a-bot.md) với [JavaScript/TypeScript SDK](../bot-sdks/javascript/overview.md) hoặc [.NET SDK](../bot-sdks/dotnet/overview.md).

## So sánh Channel Webhook và Clan Webhook

| Đặc điểm | Channel Webhook | Clan Webhook |
|---|---|---|
| Đích gửi | Một kênh (hoặc luồng) cố định | Một thành viên trong clan chỉ định ngay trên URL |
| Nơi hiển thị | Trong kênh với tên và ảnh đại diện của webhook | Trong mục **Inbox → Messages** của thành viên |
| Endpoint | <ApiBadge method="POST" path="https://webhook.mezon.ai/webhooks/{channel_id}/{token}" /> | <ApiBadge method="POST" path="https://webhook.mezon.ai/clanwebhooks/{token}/{username_or_user_id}" /> |
| Định dạng payload | **3 định dạng:** Mezon gốc (`type`), GitHub (`repository`), tương thích Discord (`content`) | Một định dạng: `{ "content": "{\"t\":\"...\"}", "attachments": [...] }` |
| Quyền tạo mới | **Manage Channel** | **Manage Channel** |
| Quyền sửa / xóa | **Manage Channel** | **Manage Clan** |
| Đổi token khi lộ | Xóa và tạo webhook mới | Bấm **Reset Token** trong cài đặt Clan Webhook |
| Hướng dẫn chi tiết | [Channel webhook](./channel-webhook.mdx) | [Clan webhook](./clan-webhook.mdx) |

## Cách hoạt động

1. Tạo Channel Webhook hoặc Clan Webhook trong phần cài đặt Mezon.
2. Sao chép URL webhook vừa tạo (URL đã chứa sẵn token xác thực bí mật).
3. Gửi yêu cầu `HTTP POST` kèm header `Content-Type: application/json` và payload hợp lệ.
4. Mezon xác thực token và gửi tin nhắn bất đồng bộ vào kênh (channel webhook) hoặc gửi trực tiếp vào hộp thư thông báo (clan webhook).

:::warning Bảo mật URL webhook như mật khẩu
Bất kỳ ai có URL webhook đều có thể gửi tin nhắn dưới danh nghĩa webhook đó. Tuyệt đối không đưa URL webhook vào mã nguồn, JavaScript phía trình duyệt hoặc nhật ký công khai — hãy truyền qua biến môi trường hoặc trình quản lý bí mật. Nếu bị rò rỉ, hãy xóa ngay channel webhook hoặc bấm **Reset Token** trên clan webhook.
:::
