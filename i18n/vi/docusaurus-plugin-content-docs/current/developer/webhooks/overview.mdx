# Webhook

Webhook là một URL bí mật dùng để đăng tin lên Mezon. Bất kỳ chương trình nào gửi được yêu cầu HTTP `POST` có JSON đều dùng được: một pipeline CI, một công cụ giám sát, một biểu mẫu. Bạn không cần bot, không cần đăng nhập và không cần SDK.

Webhook của Mezon chỉ có chiều vào: nó đăng tin vào Mezon. Nó không gửi sự kiện của Mezon về chương trình của bạn. Để phản hồi những gì xảy ra trong Mezon, hãy viết một [bot](../mezon-sdk/integration-bot-sdk/overview.md).

## Hai loại webhook {#two-kinds-of-webhooks}

| | Webhook kênh | Webhook clan |
|---|---|---|
| Đăng tới | Một kênh | Một thành viên của clan, chọn trong URL |
| Tin nhắn hiện ở | Trong kênh, gửi bằng tên và ảnh đại diện của webhook | Trong **Hộp thư** của thành viên, ở thẻ **Tin nhắn** |
| URL | `https://webhook.mezon.ai/webhooks/CHANNEL_ID/TOKEN` | `https://webhook.mezon.ai/clanwebhooks/TOKEN/USERNAME_OR_USER_ID` |
| Nội dung | `{ "type": "hook", "message": { "t": "..." } }` | `{ "content": "{\"t\":\"...\"}" }` |
| Tạo ở | Cài đặt của kênh → **Tích hợp** | Cài đặt clan → **Tích hợp** → **Webhook Clan** |
| Quyền để tạo | **Quản lý kênh** | **Quản lý kênh** |
| Hướng dẫn | [Webhook kênh](./channel-webhook.mdx) | [Webhook clan](./clan-webhook.mdx) |

Sửa hoặc xóa webhook clan cần quyền **Quản lý Clan**.

## Cách hoạt động {#how-it-works}

1. Tạo webhook trong Mezon.
2. Sao chép URL của webhook. URL chứa token của webhook.
3. Gửi một yêu cầu HTTP `POST` tới URL với nội dung JSON và header `Content-Type: application/json`.
4. Tin nhắn hiện trong kênh, hoặc trong **Hộp thư** của thành viên.

:::warning
Bất kỳ ai có URL đều đăng tin được bằng nó. Đừng để URL trong mã nguồn, log hay tin nhắn chat. Nếu URL bị lộ, hãy xóa webhook kênh rồi tạo webhook mới, hoặc nhấn **Đặt lại token** ở webhook clan.
:::
