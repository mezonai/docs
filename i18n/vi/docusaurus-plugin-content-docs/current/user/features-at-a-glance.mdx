# Tính năng chính

Mỗi dòng dẫn tới trang hướng dẫn chi tiết. Các nhãn cho biết nền tảng hoặc gói áp dụng:

- <PlatformBadge type="phone" /> ứng dụng Mezon trên Android và iPhone.
- <PlatformBadge type="computer" /> ứng dụng máy tính (Windows, macOS, Linux) và ứng dụng web.
- <PlanBadge plan="pro" /> tính năng có mức giới hạn cao hơn hoặc quyền lợi mở rộng ở [User Pro / Clan Pro](./account-and-personalization/pro-plan.mdx).

Mới dùng Mezon? Hãy đọc [Bắt đầu nhanh](./quick-start.mdx) trước.
