# Các trang web của Mezon

Ngoài các ứng dụng, Mezon có một số trang web chính thức sau.

## Dùng Mezon

| Trang web | Bạn tìm thấy gì |
|---|---|
| [mezon.ai](https://mezon.ai/) | Trang web chính. Tải ứng dụng, hoặc nhấn **Đăng Nhập** để dùng Mezon trên trình duyệt. |
| [mezon.ai/mobile-download](https://mezon.ai/mobile-download) | Một liên kết cho điện thoại: mở Google Play trên Android và App Store trên iPhone. |
| [mezon.ai/clans](https://mezon.ai/clans/) | Các clan công khai bạn có thể tham gia. Trên máy tính, nút **Khám phá** trong Mezon mở trang này. |
| [top.mezon.ai](https://top.mezon.ai/) | Danh mục Bots/Apps: các bot và ứng dụng bạn có thể thêm vào clan. |

## Mezon Đồng

| Trang web | Bạn tìm thấy gì |
|---|---|
| [mezon.ai/mezondong](https://mezon.ai/mezondong) | Thông tin về Mezon Đồng. |
| [dong.mezon.ai](https://dong.mezon.ai/) | Trình khám phá giao dịch Mezon Đồng công khai: tra cứu ví, khối và giao dịch. |

## Dành cho nhà phát triển

| Trang web | Bạn tìm thấy gì |
|---|---|
| [mezon.ai/developers](https://mezon.ai/developers/) | Mezon Developer Portal: tạo bot, ứng dụng trong kênh và ứng dụng OAuth2. |
| [Tài liệu nhà phát triển](../../developer/intro.mdx) | Hướng dẫn về các Mezon SDK, webhook, OAuth2, thoại SFU, phát trực tiếp và MMN. |
| [github.com/mezonai](https://github.com/mezonai) | Kho mã nguồn mở và các SDK chính thức của Mezon. |
