# Webhooks overview

A Mezon webhook is a secret HTTPS URL that lets any external system—CI/CD pipelines, GitHub repositories, alerting tools, or backend scripts—post messages into Mezon with a single `HTTP POST` request. No bot account, WebSocket session, or SDK is required.

Mezon webhooks are **incoming only**: they deliver data *into* Mezon. If you need to receive Mezon events, handle commands, or render interactive buttons, build a [bot](../getting-started/create-a-bot.md) with the [JavaScript/TypeScript SDK](../bot-sdks/javascript/overview.md) or [.NET SDK](../bot-sdks/dotnet/overview.md).

## Channel webhook vs. clan webhook

| Feature | Channel webhook | Clan webhook |
|---|---|---|
| Target | One specific channel (or thread) | One clan member specified in the URL |
| Where it appears | Inside the channel under the webhook's name and avatar | Inside the member's **Inbox → Messages** tab |
| Endpoint | <ApiBadge method="POST" path="https://webhook.mezon.ai/webhooks/{channel_id}/{token}" /> | <ApiBadge method="POST" path="https://webhook.mezon.ai/clanwebhooks/{token}/{username_or_user_id}" /> |
| Supported payloads | **3 formats:** Native Mezon (`type`), GitHub (`repository`), Discord-compatible (`content`) | Single format: `{ "content": "{\"t\":\"...\"}", "attachments": [...] }` |
| Permission to create | **Manage Channel** | **Manage Channel** |
| Permission to edit / delete | **Manage Channel** | **Manage Clan** |
| Token rotation | Delete and recreate the webhook | Click **Reset Token** in Clan Webhook settings |
| Guide | [Channel webhook](./channel-webhook.mdx) | [Clan webhook](./clan-webhook.mdx) |

## How it works

1. Create a channel webhook or clan webhook in Mezon settings.
2. Copy the generated webhook URL (it embeds the secret authentication token).
3. Send an `HTTP POST` with `Content-Type: application/json` and a supported payload.
4. Mezon validates the token and delivers the message asynchronously (channel webhook) or immediately as a persistent inbox notification (clan webhook).

:::warning Treat webhook URLs as secrets
Anyone who possesses a webhook URL can post messages as that webhook. Never hardcode webhook URLs in source control, client-side JavaScript, or public logs—inject them through environment variables or a secret manager. If a URL leaks, delete the channel webhook immediately or click **Reset Token** on the clan webhook.
:::
