# Webhooks

A webhook is a secret URL that posts to Mezon. Any program that can send an HTTP `POST` with JSON can use it: a CI pipeline, a monitoring tool, a form. You need no bot, no login and no SDK.

Mezon webhooks are incoming only: they post into Mezon. They do not send Mezon events to your program. To react to what happens in Mezon, write a [bot](../mezon-sdk/integration-bot-sdk/overview.md).

## Two kinds of webhooks

| | Channel webhook | Clan webhook |
|---|---|---|
| Posts to | One channel | One member of the clan, chosen in the URL |
| The message appears | In the channel, sent by the webhook's name and avatar | In the member's **Inbox**, on the **Messages** tab |
| URL | `https://webhook.mezon.ai/webhooks/CHANNEL_ID/TOKEN` | `https://webhook.mezon.ai/clanwebhooks/TOKEN/USERNAME_OR_USER_ID` |
| Body | `{ "type": "hook", "message": { "t": "..." } }` | `{ "content": "{\"t\":\"...\"}" }` |
| Create it in | The channel's settings → **Integrations** | The clan's settings → **Integrations** → **Clan Webhooks** |
| Permission to create | **Manage Channels** | **Manage Channels** |
| Guide | [Channel webhook](./channel-webhook.mdx) | [Clan webhook](./clan-webhook.mdx) |

Editing or deleting a clan webhook needs the **Manage Clan** permission.

## How it works

1. Create the webhook in Mezon.
2. Copy its URL. The URL contains the webhook's token.
3. Send an HTTP `POST` to the URL with a JSON body and the header `Content-Type: application/json`.
4. The message appears in the channel, or in the member's **Inbox**.

:::warning
Anyone who has the URL can post with it. Keep it out of source code, logs and chat messages. If it leaks, delete the channel webhook and create a new one, or click **Reset Token** on the clan webhook.
:::
