# Clan webhook

A clan webhook delivers a persistent notification directly into one clan member's **Inbox → Messages** tab, displaying the clan name alongside the webhook's name and avatar. You choose the recipient dynamically in the final URL path segment.

<ApiBadge method="POST" path="https://webhook.mezon.ai/clanwebhooks/YOUR_WEBHOOK_TOKEN/USERNAME_OR_USER_ID" />

## Permissions

| Action | Required clan permission (`api_clan_webhook.go`) |
|---|---|
| Create a clan webhook (`GenerateClanWebhook`) | **Manage Channel** |
| Update, reset token, or delete (`UpdateClanWebhookById`, `DeleteClanWebhookById`) | **Manage Clan** |

## Create a clan webhook

1. Click the clan name at the top of the channel sidebar and select **Clan Settings**.

   ![Clan menu showing Clan Settings](./images/clan-webhook-computer-01.png)

2. Open **Integrations** and click **Create Clan Webhook** (or **View Clan Webhook** if clan webhooks already exist).

   ![Integrations settings showing Create Clan Webhook](./images/clan-webhook-computer-02.png)

3. Click **New Clan Webhook**, expand the entry, and click **Copy Webhook URL**.

   ![Expanded clan webhook showing Copy Webhook URL](./images/clan-webhook-computer-03.png)

Keep the URL secret. If it ever leaks, click **Reset Token** (requires **Manage Clan**) to invalidate the old token immediately.

## Send a message

Append the target member's **username** or **user ID** (snowflake) to the copied URL and send an `HTTP POST` with `Content-Type: application/json`:

```text
https://webhook.mezon.ai/clanwebhooks/YOUR_WEBHOOK_TOKEN/USERNAME_OR_USER_ID
```

The recipient must be a current member of the clan (`CheckUserInClan`).

### Request body

```json
{
  "content": "{\"t\":\"Your weekly report is ready.\",\"mk\":[{\"type\":\"b\",\"s\":0,\"e\":18}]}",
  "attachments": [
    { "url": "https://example.com/report.png", "filetype": "image/png" }
  ]
}
```

| Field | Type | Required | Description |
|---|---|---|---|
| `content` | string | Yes | **A JSON-encoded string** (not a JSON object) representing `{ "t": "...", "mk": [...] }`. Serialize it with `JSON.stringify` / `json.dumps` / `json.Marshal` / `JsonSerializer.Serialize`. |
| `attachments` | array | No | Array of `{ "url", "filetype" }`. Every `url` is validated (`ValidateURL` requires full scheme + host). Mezon embeds the **first** attachment (`AttachmentLink` / `AttachmentType`) and sets `HasMoreAttachment = true` when more than one attachment is supplied (`api_clan_webhook.go`). |

### Examples

Set `CLAN_WEBHOOK_URL="https://webhook.mezon.ai/clanwebhooks/YOUR_WEBHOOK_TOKEN/USERNAME_OR_USER_ID"` in your environment.

import json
import os
import urllib.request

body = {
    "content": json.dumps({"t": "Your weekly report is ready."}),
    "attachments": [{"url": "https://example.com/report.png", "filetype": "image/png"}],
}

req = urllib.request.Request(

    data=json.dumps(body).encode("utf-8"),
    headers={"Content-Type": "application/json"},
    method="POST",
)

    print(res.status, res.read().decode())

}

## Error responses

| HTTP status | Response body | Cause |
|---|---|---|
| `200` | *(empty)* | Notification queued and badge updated. |
| `400` | `Invalid JSON` | Body is not valid JSON. |
| `400` | `invalid token` | Token is invalid, deleted, or was reset. |
| `400` | `User not in clan` | Target user ID / username does not belong to the clan. |
| `400` | `Invalid attachment URL` | An attachment `url` lacks a valid scheme and host. |
| `404` | `Not Found` | URL is missing the trailing `/{username_or_user_id}` path segment. |
