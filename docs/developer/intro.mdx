# Mezon developer documentation

Mezon is an extensible messaging, voice, streaming, and payments platform. Every bot, channel app, and OAuth2 client starts in the [Mezon Developer Portal](https://mezon.ai/developers/applications), where you register an application ID and issue credentials.

## Platform architecture

All bots and clients authenticate once against the Mezon Gateway (`gw.mezon.ai`), which assigns regional/shard endpoints for realtime sockets and HTTP APIs. From there, bots stay connected over persistent TLS abridged TCP sockets to `mezon-proto-server` while media, payments, and AI agent events flow through dedicated services.

```mermaid
flowchart LR
    Client["Bot / Client / Channel App"]
    GW["Mezon Gateway (gw.mezon.ai)"]
    Proto["Realtime Proto-Server (TLS Abridged TCP / WS)"]
    API["Mezon API (PostgreSQL / Business RPCs)"]
    SFU["Voice & Meeting SFU (WebRTC)"]
    Stream["Streaming Server (WHIP / LL-HLS)"]
    MMN["Mezon Dong Network (MMN / ZK)"]

    Client -->|"1. HTTPS AuthenticateApp / OAuth2"| GW
    GW -->|"2. JWT + api_url, ws_url, tcp_url, id_token"| Client
    Client <-->|"3. 0xEF TLS TCP Envelope & RPCs"| Proto
    Proto <-->|"NATS request/event bus"| API
    Client -->|"4. Media grants (GenerateMeetToken / GetStreamPlayback)"| Proto
    Client <-->|"5a. WebRTC voice/video"| SFU
    Client -->|"5b. WHIP ingest / LL-HLS playback"| Stream
    Client -->|"5c. ZK-proven token transfers"| MMN
```

## Integration surfaces at a glance

| Integration type | Best for | Runtime & transport | Starting point |
| --- | --- | --- | --- |
| **Bots** | Commands, interactive cards, moderation, polls, streaming grants, token transfers | Persistent Node.js (`mezon-sdk`) or .NET (`Mezon.Net.Sdk`) over TLS TCP | [Create a bot](./getting-started/create-a-bot.md) |
| **Channel apps** | Full web applications launched inside a clan channel with signed user context | Any web stack verifying HMAC launch data (`?data=`) | [Create a channel app](./getting-started/create-a-channel-app.md) |
| **Webhooks** | One-way notifications from CI/CD, monitoring, or backend jobs | Single HTTPS `POST` — no bot account or SDK required | [Webhooks overview](./webhooks/overview.mdx) |
| **OAuth2** | "Sign in with Mezon" on external websites | Standard Authorization Code flow + ID tokens | [OAuth2 flow](./oauth2/authorization-code-flow.mdx) |
| **Light SDK & Chat Widget** | Embedded chat experiences for external web apps | Browser JS (`mezon-light-sdk`, `mezon-chat-widget`) | [Light SDK](./channel-apps-and-widgets/light-sdk.md) |
| **Voice SFU & Streaming** | Voice bots, meeting recorders, live stream publishers | WebRTC SFU SDKs (6 languages) + WHIP / LL-HLS | [Media overview](./media-voice-and-streaming/overview.md) |
| **AI & MCP** | Voice/room AI session events and LLM tool integration | Agent SSE (`connectMezonAgentSSE`) and MCP | [AI agent events](./ai-and-mcp/ai-agent-events.md) |
