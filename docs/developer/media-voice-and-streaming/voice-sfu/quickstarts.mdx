# Voice SFU quickstarts

Every example below joins a Mezon voice room (`CHANNEL_TYPE_MEZON_VOICE = 10`) using the `sfuUrl` and HS256 JWT `token` returned by [`GenerateMeetToken`](./concepts-and-tokens.md#obtaining-a-meet-token-generatemeettoken). Remember that every SFU session starts **muted on the server**—enable the microphone (or push-to-talk for audience roles) before writing audio.

:::warning Pre-1.0 SDKs
All six SFU SDKs are pre-1.0. For production bots, replace static token helpers (`TokenProvider.fixed` / `sfu.StaticToken`) with a live `TokenProvider` function that calls `GenerateMeetToken` whenever the SDK requests a `reconnect`, `expiring`, or `rejected` refresh.
:::

```bash
go get github.com/mezonai/mezon-sfu-sdk-go
```

```go
package main

import (
	"context"
	"log"
	"os"
	"time"

	sfu "github.com/mezonai/mezon-sfu-sdk-go"
	"github.com/pion/webrtc/v4/pkg/media"
)

func joinVoice(ctx context.Context, opusFrame []byte) error {
	room := sfu.NewRoom(sfu.Options{
		Handlers: sfu.Handlers{
			OnTrackSubscribed: func(track *sfu.RemoteTrack, p *sfu.RemoteParticipant) {
				go func() {
					for {
						pkt, err := track.ReadRTP() // Opus or VP8 RTP; io.EOF when unsubscribed
						if err != nil {
							return
						}
						_ = pkt
					}
				}()
			},
			OnMessageReceived: func(text string, from sfu.MessageSender) {
				log.Println(from.UserID, text)
			},
		},
	})

	if err := room.Connect(ctx, os.Getenv("MEZON_SFU_URL"), sfu.StaticToken(os.Getenv("MEZON_SFU_TOKEN"))); err != nil {
		return err
	}
	defer room.Disconnect()

	if err := room.LocalParticipant().SetMicrophoneEnabled(ctx, true); err != nil {
		return err
	}

	// Include RFC 6464 audio level (0 loudest..127 silence) for fixed-slot VAD
	return room.LocalParticipant().Microphone().WriteSampleWithLevel(
		media.Sample{Data: opusFrame, Duration: 20 * time.Millisecond},
		30,
	)
}
```

```rust
use std::time::Duration;
use mezon_sfu::{Options, Room, RoomEvent, TokenProvider};

async fn run(url: &str, token: &str, opus_frame: bytes::Bytes) -> mezon_sfu::Result<()> {
    let (room, mut events) = Room::new(Options::default());
    room.connect(url, TokenProvider::fixed(token)).await?;

    room.local_participant().set_microphone_enabled(true).await?;
    room.local_participant()
        .microphone()
        .write_opus(opus_frame, Duration::from_millis(20), Some(30))
        .await?;

    while let Some(event) = events.recv().await {
        if let RoomEvent::TrackSubscribed(track, participant) = event {
            tokio::spawn(async move {
                while let Some(packet) = track.read_rtp().await {
                    let _ = (&participant, packet);
                }
            });
        }
    }

    room.disconnect().await;
    Ok(())
}
```

## Audience & Push-to-Talk pattern

To join as a listener and speak only on demand:

- **TypeScript:** `new Room({ role: "audience" })` → `await room.localParticipant.setPushToTalk(true)`
- **Go:** `sfu.NewRoom(sfu.Options{Role: sfu.RoleAudience})` → `room.LocalParticipant().SetPushToTalk(ctx, true)`
- **Rust:** `Options { role: Role::Audience, ..Default::default() }` → `room.local_participant().set_push_to_talk(true).await?`
- **Kotlin:** `Options(role = Role.AUDIENCE)` → `room.localParticipant.setPushToTalk(true)`
- **Python:** `Options(role=Role.AUDIENCE)` → `await room.local_participant.set_push_to_talk(True)`
- **.NET:** `new RoomOptions { Role = Role.Audience }` → `await room.LocalParticipant.SetPushToTalkAsync(true)`
