# Features at a glance

This list shows what you can do in Mezon today, in the apps released by 19 November 2026: the web app 2.1.5, the desktop app 2.1.22, and the Android and iPhone apps 2.1.4.

Each line links to the page that explains it. The badges show where the feature is:

- <span className="badge badge--secondary">Phone</span> the Mezon app for Android and iPhone.
- <span className="badge badge--secondary">Computer</span> the desktop app (Windows, macOS, Linux) and the web app in a browser.

New to Mezon? Start with the [quick start](./quick-start.mdx).
