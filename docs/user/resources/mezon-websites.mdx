# Mezon websites

Besides the apps, Mezon has several official websites.

## Use Mezon

| Website | What you find there |
|---|---|
| [mezon.ai](https://mezon.ai/) | The main website. Download the apps, or click **Login** to use Mezon in your browser. |
| [mezon.ai/mobile-download](https://mezon.ai/mobile-download) | One link for phones: it opens Google Play on Android and the App Store on an iPhone. |
| [mezon.ai/clans](https://mezon.ai/clans/) | Public clans you can join. On a computer, the **Discover** button in Mezon opens this page. |
| [top.mezon.ai](https://top.mezon.ai/) | The Bots/Apps directory: bots and apps you can add to your clan. |

## Mezon Dong

| Website | What you find there |
|---|---|
| [mezon.ai/mezondong](https://mezon.ai/mezondong) | Information about Mezon Dong. |
| [dong.mezon.ai](https://dong.mezon.ai/) | The public Mezon Dong transaction explorer: look up wallets, blocks, and transactions. |

## Developers

| Website | What you find there |
|---|---|
| [mezon.ai/developers](https://mezon.ai/developers/) | The Mezon Developer Portal: create bots, channel apps, and OAuth2 clients. |
| [Developer docs](../../developer/intro.mdx) | Guides for the Mezon SDKs, webhooks, OAuth2, voice SFU, streaming, and MMN. |
| [github.com/mezonai](https://github.com/mezonai) | Official Mezon open-source repositories and SDKs. |
