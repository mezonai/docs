# Message actions

These actions work in direct messages, group chats and clan channels.

## Open the message menu

<Tabs groupId="platform" queryString>
<TabItem value="phone" label="Phone">

Press and hold a message. A menu opens with a row of emoji at the top and the actions below.

<Image src={messageActionsPhone01} alt="The menu of a message: Give Coffee, Reply, Forward, Forward All Nearby, Copy Text, Share Text and Add To Inbox" width={270} />

</TabItem>
<TabItem value="computer" label="Computer">

Right-click a message. A menu opens with the actions.

<Image src={messageActionsComputer01} alt="The menu of another person's message: Add Reaction, Give A Coffee, Reply, Forward Message, Copy Text, Pin Message, Mark Unread, Add To Inbox and Report Message" />

</TabItem>
</Tabs>

The menu shows only the actions you can use. For example, **Edit Message** appears only on your own messages.

## What each action does

The table uses the labels of the computer apps. Where a phone app uses a different label, the table says so.

| Action | What it does | Where |
|---|---|---|
| Reaction | Adds an emoji under the message. On a phone, tap an emoji in the top row. On a computer, click **Add Reaction**. | Phone, computer |
| **Reply** | Writes an answer linked to the message. | Phone, computer |
| **Edit Message** | Changes the text of your own message. | Phone, computer |
| **Delete Message** | Deletes the message after you confirm. | Phone, computer |
| **Forward Message** | Sends a copy to other conversations or channels. Search, select one or more, add an optional message, then send. On Android the label is **Forward**. | Phone, computer |
| **Forward All Messages** | Forwards this message and the messages right after it from the same person. On phones the label is **Forward All Nearby**. | Phone, computer |
| **Copy Text** | Copies the text. On a computer, select part of the text first to see **Copy Selected Text**. | Phone, computer |
| **Share Text** | Opens your phone's share menu, so you can send the text to another app. | Phone |
| **Pin Message** | Pins the message so everyone finds it later. See [Pinned messages](../clan/create-your-own-clan/manage-clan/clan-structure/channels/text-channel/pinned-messages.mdx). | Phone, computer |
| **Mark Unread** | Marks the message as unread, so you can come back to it. | Computer |
| **Add To Inbox** | Saves the message in your Inbox. See [Inbox](../clan/create-your-own-clan/manage-clan/clan-structure/channels/text-channel/inbox.mdx). | Phone, computer |
| **Report Message** | Reports the message to Mezon. Pick the problem, then click **Submit Report**. On phones the label is **Report**. | Phone, computer |
| **Give A Coffee** | Gives the author a coffee paid with Mezon Dong. On Android the label is **Give Coffee**. See [Give a coffee](../mezon-dong/send-and-transfer-mezon-dong.mdx). | Phone, computer |

Who can delete messages:

- Everyone can delete their own messages.
- In a group chat, the person who created the group can delete any message (not in the iPhone app).
- In a clan, people whose role has the **Delete Messages** permission can delete other people's messages.

In clan channels the menu also has **Create Thread** and **Topic Discussion**. See [Threads and topics](./threads-and-topics.mdx).

## Send a voice message

<Tabs groupId="platform" queryString>
<TabItem value="phone" label="Phone">

1. Press and hold the microphone at the right of the message box.
2. Speak while you hold it.
3. Release to send. To cancel, slide your finger to the left before you release.

<Image src={messageActionsPhone02} alt="A voice message being recorded, with the timer and Slide to cancel" width={270} />

The first time, allow Mezon to use the microphone.

</TabItem>
<TabItem value="computer" label="Computer">

1. Press and hold the microphone at the right of the message box.
2. Speak while you hold it.
3. Release it. The recording is added to the message box.
4. Press **Enter** to send it.

</TabItem>
</Tabs>

## Send photos and files

<Tabs groupId="platform" queryString>
<TabItem value="phone" label="Phone">

1. Tap **+** at the left of the message box.
2. Pick photos or videos, or tap **Upload a file**.
3. Tap send.

<Image src={messageActionsPhone03} alt="The attach panel with recent photos and Upload a file marked" width={270} />

</TabItem>
<TabItem value="computer" label="Computer">

1. Click **+** at the left of the message box.
2. Click **Upload a File** and choose the files.
3. Press **Enter** to send.

You can also drag files into the conversation or paste them.

</TabItem>
</Tabs>

:::note
In the web app, the desktop app and the Android app, each image can be up to 50 MB and each other file up to 1 GB. On a computer you can send up to 50 files in one message. On a phone you can pick up to 20 at a time.
:::

## Format your text

Type these marks around your text. Mezon shows the result when you send the message.

| You type | You get |
|---|---|
| `**bold**` | **bold** |
| `*italic*` or `_italic_` | *italic* |
| `~~strikethrough~~` | ~~strikethrough~~ |
| `` `code` `` | `code` |
| ` ``` ` on the lines before and after | a code block |
| `# Heading` at the start of a line | a heading. Use `#` to `######` for six sizes. |
| `- item` or `* item` at the start of a line | a bulleted list |
| `1. item` at the start of a line | a numbered list |
| `> text` at the start of a line | a quote |
| `[link text](https://example.com)` | a link with your own text |

The desktop app does not show lists, quotes or links with your own text; it shows them as you typed them. The web app and the phone apps show everything in the table.

## Get someone's attention with Buzz

Buzz sends a short message that rings for the people in the conversation or channel. It can have up to 160 characters.

- **Phone:** tap the menu button next to **+** in the message box, then tap **Buzz**.
- **Computer:** press **Ctrl+G** in a conversation or channel, type your message and send it.
