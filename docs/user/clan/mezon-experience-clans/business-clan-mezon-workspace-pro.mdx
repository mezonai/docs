# Mezon WorkSpace Pro

Mezon WorkSpace Pro is a sample clan made by Mezon for teams at work. Join it to see how a team can use a clan. A clan for a team often has:

- categories and channels for each project or department
- voice channels for meetings and screen sharing
- roles that decide who can see and manage which channels

Join with this invite link: [Mezon WorkSpace Pro](https://mezon.ai/invite/1971125963139846144).

To set up a clan like this for your own team, see [Create a clan](../create-your-own-clan/create-a-clan.mdx) and [Roles and permissions](../create-your-own-clan/manage-clan/overview-settings/roles-and-permissions-management.mdx).
