# Mezon Campus Hub

Mezon Campus Hub is a sample clan made by Mezon for students. Join it to see how a class or a study group can use a clan. A clan for students often has:

- channels for each subject, for questions and for sharing files
- voice channels to study together
- events for tests and deadlines

Join with this invite link: [Mezon Campus Hub](https://mezon.ai/invite/1971118566472159232).

To set up a clan like this for your own class, see [Create a clan](../create-your-own-clan/create-a-clan.mdx). The **Study Group** and **School Club** templates are a good start.
