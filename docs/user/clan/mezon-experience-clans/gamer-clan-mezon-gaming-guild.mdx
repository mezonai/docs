# Mezon Gaming Guild

Mezon Gaming Guild is a sample clan made by Mezon for gamers. Join it to see how a gaming group can use a clan. A clan for gamers often has:

- voice channels to talk while you play
- channels for each game and for team plans
- events for matches and game nights

Join with this invite link: [Mezon Gaming Guild](https://mezon.ai/invite/1971122683512885248).

To set up a clan like this for your own group, see [Create a clan](../create-your-own-clan/create-a-clan.mdx). The **Gaming** template is a good start.
