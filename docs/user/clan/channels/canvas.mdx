# Canvas

A canvas is a note that stays in a text channel or thread, so important information does not get lost in the chat. A canvas has a title and text with headings, lists, checklists, quotes, code and links.

## Create a canvas

You create and edit a canvas on a computer.

1. Open the text channel or thread.
2. Click the **Canvas** button at the top right.
3. Click **Create**.

<Image src={canvasComputer01} alt="The Canvas panel with the Create button" />

4. Type a title where it says **Your canvas title**, then write the text.
5. Click **Save** at the bottom.

## Who can edit a canvas

- Anyone in the channel can open and read a canvas.
- Only the person who created a canvas can edit it.

## Read a canvas

<Tabs groupId="platform" queryString>
<TabItem value="phone" label="Phone">

1. Open the text channel.
2. Tap the channel name at the top.
3. Open the **Canvas** tab and tap a canvas.

On a phone you can read a canvas but not create or edit one.

</TabItem>
<TabItem value="computer" label="Computer">

1. Click the **Canvas** button at the top right of the channel.
2. Click a canvas in the list.

</TabItem>
</Tabs>
