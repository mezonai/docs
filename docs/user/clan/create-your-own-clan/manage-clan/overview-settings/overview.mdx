# Overview

**Overview** holds the clan name, the clan picture and banner, and the system message settings. The clan owner and members with the **Administrator** permission can change them.

## Change the name, picture or banner

<Tabs groupId="platform" queryString>
<TabItem value="phone" label="Phone">

1. Open the clan, tap the clan name, then tap **Settings**.
2. Tap **Overview**.
3. Change the **Clan name**, tap the clan picture to change it, or tap the banner to change it.
4. Save your changes.

</TabItem>
<TabItem value="computer" label="Computer">

1. Open **Clan Settings**. **Overview** opens first.
2. Change what you need:
   - Click **Upload Image** to change the clan picture.
   - Type a new name under **CLAN NAME**.
   - Under **CLAN BANNER BACKGROUND**, click **Upload Background**. The banner shows at the top of your channel list.
3. A bar appears at the bottom. Click **Save Changes**, or **Reset** to undo.

<Image src={computerOverview} alt="The Overview page with the clan picture, the clan name, the banner and the system messages channel" />

</TabItem>
</Tabs>

### Picture and banner sizes

| Image | Recommended size | Largest file |
|---|---|---|
| Clan picture | at least 512 x 512 pixels (smallest 128 x 128) | 1 MB |
| Banner | at least 960 x 540 pixels, shape 16:9 | 10 MB |

The name follows the same rules as when you [create a clan](../../create-a-clan.mdx).

## Choose where system messages go

Mezon posts system messages in one channel, for example when someone joins. Under **SYSTEM MESSAGES CHANNEL** (on phones, the system messages section), choose the channel. Then turn each message on or off:

- **Send a random welcome message when someone joins this clan.**
- **Send helpful tips for clan setup.**
- **Send a log when an action is applied to the clan**

## Turn off anonymous mode

Members can sometimes post without showing their name. To stop this in your clan, turn on **Prevent Anonymous** (phones: **Anonymous mode**). Its description says **Prevent users from using anonymous mode**.

## Phone only

- **Default notifications**: the level for members who never chose one. See [Notifications in a clan](../managing-notifications-in-a-clan.mdx).
- **Delete clan** (owner only). See [Delete a clan](./delete-clan.mdx).
