# Search

Search finds messages in the channel you have open, including its threads that you are in. In a direct message, it searches that conversation.

## Search for messages

<Tabs groupId="platform" queryString>
<TabItem value="phone" label="Phone">

1. Open the channel and tap the channel name at the top.
2. Tap **Search**.
3. Type the words you are looking for.
4. Tap a result to go to the message.

</TabItem>
<TabItem value="computer" label="Computer">

1. Click the **Search** box at the top right of the channel. In the desktop app you can also press **Ctrl+F** (**Cmd+F** on a Mac).

<Image src={searchComputer01} alt="The search box with the search options: sender, mentioned user and attachments" />

2. Type the words you are looking for and press **Enter**.
3. Click **Jump** on a result to go to the message.

</TabItem>
</Tabs>

## Use filters

On a computer, type one of these signs in the search box. A list appears so you can pick a person or a type.

| Type | Filter | Finds |
|---|---|---|
| `>` | `from:` | Messages sent by one person. Example: `>Nam`. |
| `~` | `mentions:` | Messages that mention one person. Example: `~Mai`. |
| `&` | `has:` | Messages with an **image**, a **video** or a **link**. |

You can use several filters and words together. Example: type `>` and pick Nam, then type `&` and pick **image**. The box shows `from:Nam has:image` and finds the pictures that Nam sent.

On a phone, the filter button offers `from:` and `mentions:`.

## Search for an exact phrase

Put the words in quotes, for example `"Friday meeting"` or `'Friday meeting'`. Mezon then finds only messages with these words next to each other, in this order. Single and double quotes work the same way.
