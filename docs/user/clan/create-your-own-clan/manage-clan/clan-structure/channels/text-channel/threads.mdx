# Threads

A thread is a small channel inside a text channel, with its own name. Use a thread for a subject that needs a longer discussion, so the main channel stays easy to follow. A thread shows under its channel in the channel list.

## Thread or topic?

| | Thread | Topic |
|---|---|---|
| Starts from | The **Threads** panel, or a message | One message |
| Has a name | Yes | No |
| Can be private | Yes | No |
| Shows in the channel list | Yes | No. You open it from the message, or from the Inbox. |
| Who can start one | People with the **Manage Threads** permission | Anyone who can send messages in the channel |

See [Topic](./topic.mdx) for short discussions about one message.

## Create a thread

You need the **Manage Threads** permission. The clan owner always has it. Without it, you do not see **Create** or **Create Thread**.

<Tabs groupId="platform" queryString>
<TabItem value="phone" label="Phone">

1. Press and hold the message you want to discuss.
2. Tap **Create Thread**.
3. Type the thread name.
4. To make it private, turn on **Private Thread**.
5. Type the first message and send it.

</TabItem>
<TabItem value="computer" label="Computer">

1. Click the **Threads** button at the top right of the channel.
2. Click **Create**.

<Image src={threadsComputer01} alt="The Threads panel with the Create button" />

3. Type a name in **Thread Name**.

<Image src={threadsComputer02} alt="The New Thread panel with Thread Name, Private Thread and the message box" />

4. To make it private, tick **Private Thread**. Only the people you invite and moderators can see it.
5. Type the first message and press **Enter**.

You can also right-click a message and click **Create Thread**.

</TabItem>
</Tabs>

The thread appears under the channel in the channel list. A thread name must be longer than 3 characters. To invite people, mention them with **@** in the thread.

## Find threads

- **Computer:** click the **Threads** button. The list shows active threads, threads you joined and archived threads.
- **Phone:** tap the channel name at the top, then tap **Threads**.

Threads with no new messages for a while stop showing in the channel list. The channel's **Hide After Inactivity** setting decides when. You can still find them in the threads list.
