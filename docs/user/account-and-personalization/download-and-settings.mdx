# Download and install Mezon

Install Mezon from the official stores, or use it in a web browser without installing anything.

## What you need

| Device | Minimum | Where to get Mezon |
|---|---|---|
| Android phone or tablet | Android 7.0 | Google Play |
| iPhone or iPad | iOS 13.0 | App Store |
| Windows computer | Windows 10 (version 1809), 64-bit | Microsoft Store |
| Mac | macOS 13.0 | Mac App Store |
| Linux computer | 64-bit Debian or Ubuntu | `.deb` file from [mezon.ai](https://mezon.ai) |
| Any computer with a web browser | | [mezon.ai](https://mezon.ai) |

## Install Mezon

<Tabs groupId="platform" queryString>
<TabItem value="phone" label="Phone">

**Android**

1. Open [Mezon on Google Play](https://play.google.com/store/apps/details?id=com.mezon.mobile).
2. Check that the publisher is **NCCPLUS**.
3. Tap **Install**.

**iPhone or iPad**

1. Open [Mezon on the App Store](https://apps.apple.com/app/mezon/id6502750046).
2. Check that the provider is **NCCPLUS VIETNAM JOINT STOCK COMPANY**.
3. Tap **Get**.

:::tip
One link works on every phone: [mezon.ai/mobile-download](https://mezon.ai/mobile-download). It opens Google Play on Android and the App Store on an iPhone. You can print it as a QR code for your team.
:::

</TabItem>
<TabItem value="computer" label="Computer">

**Windows**

1. Open [Mezon in the Microsoft Store](https://apps.microsoft.com/detail/9pf25lf1fj17).
2. Click **Get** or **Install**. The publisher is **NCCPLUS**.

**Mac**

1. Open [Mezon Desktop in the Mac App Store](https://apps.apple.com/app/mezon-desktop/id6756601798?mt=12).
2. Click **Get**, then **Install**.

**Linux (Debian or Ubuntu)**

1. Go to [mezon.ai](https://mezon.ai) and click the download button at the top of the page.
2. Choose **Linux**. Your browser downloads a `.deb` file.
3. Open the file with your software installer and install it.
4. Start Mezon.

The file on the website can be an older version. Mezon then offers the newest one inside the app: click **Update available — click to install**, then **Restart to update**.

**Web browser (no installation)**

Go to [mezon.ai](https://mezon.ai) and click **Login**.

</TabItem>
</Tabs>

## After you install

1. Open Mezon and [log in](./sign-up-and-log-in.mdx). Your first login also creates your account.
2. Allow **Notifications** when Mezon asks, so you see new messages. Phones ask right after you log in. The desktop app asks when it starts.
3. Allow the other permissions when Mezon asks for them, the first time you use a feature:
   - **Microphone**, when you join a voice channel, record a voice message or make a call.
   - **Camera**, when you turn on video or scan a QR code.
   - **Photos**, when you send a picture.

The desktop app opens in English. To change the language, see [Profile and settings](./personalization-settings.mdx).

## Keep Mezon up to date

- **Phones, Windows and Mac:** the stores update Mezon. On a phone, Mezon tells you when a new version is ready.
- **Linux:** Mezon checks for updates by itself. You can also open **Settings** and click **Check for updates**.
- **Web:** you always get the newest version.
