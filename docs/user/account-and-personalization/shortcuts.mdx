# Keyboard shortcuts and text formatting

This page lists the keyboard shortcuts of the web app 2.1.5 and the desktop app 2.1.22, and the marks you can type to format a message.

<Tabs groupId="platform" queryString>
<TabItem value="phone" label="Phone">

The phone apps have no keyboard shortcuts. You find the same actions in the message box:

- **Buzz:** a message with a ringing sound, to get attention. Tap the menu button next to **+** in the message box, then tap **Buzz**.
- **Anonymous:** post in a clan channel without your name. Tap the menu button next to **+** in the message box, then tap **Anonymous**. To stop, tap **Turn off anonymous** (iPhone: **Anonymous On**).

## Keyboard shortcuts

| Action | Web app | Desktop app on Windows or Linux | Desktop app on a Mac |
|---|---|---|---|
| Jump to a clan, channel or person (quick switcher) | Ctrl+K (Mac: ⌘K) | Ctrl+K | ⌘K |
| Search messages in this channel | Ctrl+F (Mac: ⌘F) | Ctrl+F | ⌘F |
| Send the message | Enter | Enter | Enter |
| New line without sending | Shift+Enter | Shift+Enter | Shift+Enter |
| Send a Buzz | Ctrl+G (also on a Mac) | Ctrl+G | Ctrl+G |
| Turn anonymous mode on or off (clan channels) | Ctrl+Shift+Enter (Mac: ⌘+Shift+Enter) | Ctrl+Shift+Enter | ⌘+Shift+Enter |
| Bold the selected text | Ctrl+B (Mac: ⌘B) | — | — |
| Undo / redo while typing | Ctrl+Z / Ctrl+Y (Mac: ⌘Z / ⌘Y) | Ctrl+Z / Ctrl+Y or Ctrl+Shift+Z | ⌘Z / ⌘Y or ⌘+Shift+Z |
| Paste as plain text | Ctrl+Shift+V (Mac: ⌘+Shift+V) | Ctrl+Shift+V | ⌘+Shift+V |
| Talk while your microphone is off (in a voice channel) | Hold Space | Hold Space | Hold Space |
| Go back / forward | Your browser's keys | Alt+← / Alt+→ | ⌘[ / ⌘] |
| Quit Mezon | — | Ctrl+Q | ⌘Q |
| Hide the window / minimize / hide Mezon | — | — | ⌘W / ⌘M / ⌘H |

:::tip
In the quick switcher, start with **@** to find people or **#** to find channels.
:::

A dash (—) means the app has no shortcut for that action. Hold Space works only when you are not typing in a box.

## Format text in a message

Type these marks around your text. The web app and the desktop app show the message formatted.

| Type | You get |
|---|---|
| `**text**` | **bold** |
| `*text*` or `_text_` | *italic* |
| `~~text~~` | ~~strikethrough~~ |
| `` `text` `` | `code` |
| ```` ``` ```` on the line before and after | a code block |
| `# ` at the start of a line | a big heading; use `#` to `######` for six sizes |

In the web app you can also start a line with `- ` or `1. ` for a list, or with `> ` for a quote, and write `[text](https://example.com)` for a link with your own text.
