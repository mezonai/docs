# Build your own bot or app

Developers can build their own bots and apps for Mezon, and connect other services with webhooks.

## Where to start

- **Developer portal:** create a bot or an app at [mezon.ai/developers](https://mezon.ai/developers/). Click **New Application or Bot**.
- **Developer docs:** start with the [Mezon developer documentation](../../developer/intro.mdx).
- **Bots:** [Create a bot](../../developer/quick-start/creating-mezon-bot.md), then read about the [bot SDK](../../developer/mezon-sdk/integration-bot-sdk/overview.md).
- **Apps:** [Create a channel app](../../developer/quick-start/creating-mezon-app.md), then read about the [Channel App SDK](../../developer/mezon-sdk/channel-app-sdk/overview.md).
- **Webhooks:** send messages into Mezon from other services. See the [webhooks overview](../../developer/webhooks/overview.mdx). Clan admins find webhooks in **Clan Settings** → **Integrations**.
